REGION BACKGROUND IMAGES
========================

Save your region background images here with this naming convention:

Format: region_{biome}_{variant}.png

Examples:
- region_plains_01.png     (for plains biome, variant 1)
- region_plains_02.png     (for plains biome, variant 2)
- region_forest_01.png     (for forest biome)
- region_mountains_01.png  (for mountains biome)
- region_ocean_01.png      (for ocean biome)

Current Setup:
- region_plains_01.png  <- YOUR IMAGE GOES HERE (the one you just uploaded)

File Requirements:
- Format: PNG or JPG
- Recommended size: 1920x1080 or larger
- Quality: High resolution for best display

How the game uses these:
1. Game checks for region_plains_01.png when in plains biome
2. If image exists, displays it as background
3. If image missing, falls back to gradient background

To add your image:
1. Right-click your uploaded image
2. Save as: region_plains_01.png
3. Place in this folder: C:\Users\durha\idlegame\assets\backgrounds\regions\
4. Refresh the game - it should appear automatically!
