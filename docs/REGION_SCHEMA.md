# Region Definition Schema

## Overview

This document defines the standardized format for region definitions in the game. Regions are hex tiles on the world map that players can explore through the Navigation system.

## Current System Architecture

### 1. **WorldMap** (Generated Procedurally)
- Location: `GameEngine.definitions.worldMap`
- Generated by: `GameEngine.generateWorldMap()` at initialization
- Structure: Object with region IDs as keys (e.g., `"region_-3_-4"`)

### 2. **Biomes** (Content Templates)
- Location: `GameDefinitions.biomes`
- Purpose: Define what content can be discovered in each biome type
- Biome Types: plains, forest, mountains, tundra, desert, swamp, coast

### 3. **Enemies** (Combat Encounters)
- Location: `GameDefinitions.enemies`
- Filtered by region distance for discoverableEnemies

### 4. **Missions** (Quests)
- Location: `GameDefinitions.missions`
- Linked to regions via `metadata.region` field

## Complete Region Schema

```javascript
{
    // ========== BASIC INFORMATION ==========
    name: "The Scar",                    // Display name
    description: "A massive crater...",  // Lore description
    icon: "🌾",                          // Emoji icon (inherited from biome)
    biome: "plains",                     // Biome type (determines content pools)
    backgroundImage: "assets/...",       // Region-specific background (null = use biome default)

    // ========== COORDINATES & NAVIGATION ==========
    hexCoords: {
        q: -3,   // Axial coordinate (horizontal axis)
        r: -4    // Axial coordinate (diagonal axis)
    },
    navigationRequirement: 1,            // Min navigation level to unlock
    complication: 1.0,                   // Discovery difficulty multiplier (1.0 = normal)

    // ========== ADJACENT REGIONS ==========
    adjacent: {
        "E": "region_-2_-4",             // East neighbor
        "NE": "region_-2_-5",            // Northeast neighbor
        "NW": "region_-3_-5",            // Northwest neighbor
        "W": "region_-4_-4",             // West neighbor
        "SW": "region_-4_-3",            // Southwest neighbor
        "SE": "region_-3_-3"             // Southeast neighbor
    },

    // ========== DISCOVERABLE CONTENT ==========
    // These arrays define what can be found during navigation discovery attempts

    discoverableNodes: [                 // Gathering nodes (from biome definition)
        "copperVein",                    // Mining nodes
        "oakTree",                       // Logging nodes
        "pond",                          // Fishing nodes
        "grassland",                     // Hunting nodes
        "berryBush"                      // Foraging nodes
    ],

    discoverableCraftingStations: [      // Crafting stations (from biome definition)
        "basicForge",                    // Forging stations
        "campfire",                      // Cooking stations
        "sewingKit"                      // Textiles stations
    ],

    discoverableEnemies: [               // Combat encounters (filtered by distance/level)
        "scout",                         // Enemy IDs that can spawn here
        "soldier"
    ],

    discoverableLocations: [             // Special locations/events
        {
            id: "abandonedCamp",
            name: "Abandoned Camp",
            type: "discovery",           // discovery, event, landmark
            description: "A deserted campsite...",
            discoveryChance: 0.05,       // 5% chance per discovery attempt
            rewards: {
                gold: 50,
                items: [{ itemId: "lightRations", amount: 5 }],
                exp: { navigation: 25 }
            },
            oneTime: true                // Can only be discovered once
        }
    ],

    availableMissions: [                 // Missions available in this region
        "tutorial_elder",                // Mission IDs (from GameDefinitions.missions)
        "gather_wood"
    ],

    // ========== EXPERIENCE & REWARDS ==========
    experienceRates: {
        // Base XP per successful discovery attempt
        navigation: {
            baseXP: 10,                  // Base XP for any discovery
            nodeDiscovery: 15,           // XP for discovering a gathering node
            stationDiscovery: 25,        // XP for discovering a crafting station
            enemyDiscovery: 20,          // XP for discovering an enemy
            pathDiscovery: 30,           // XP for discovering an exit path
            locationDiscovery: 50        // XP for discovering a special location
        },
        // Bonus XP for first-time discoveries
        firstTimeBonus: 2.0              // Multiplier for first discovery of each type
    },

    // ========== REGION EFFECTS ==========
    environmentalEffects: {
        // Passive effects while in this region
        movementSpeed: 1.0,              // Movement speed multiplier (1.0 = normal)
        discoveryChanceModifier: 0,      // Flat % bonus to discovery chance
        resourceYieldMultiplier: 1.0,    // Gathering yield multiplier

        // Optional hazards
        hazards: [
            {
                type: "cold",            // cold, heat, poison, radiation, etc.
                severity: 0,             // 0-10 scale
                damagePerTick: 0,        // HP damage over time
                requiredResistance: null // Item/attribute requirement to negate
            }
        ]
    },

    // ========== PROGRESSION RESTRICTIONS ==========
    requiredMissionToLeave: null,        // Mission ID that must be completed to travel away
    requiredItemsToEnter: {},            // { itemId: quantity } requirements to enter
    levelGate: {                         // Multi-skill requirements
        navigation: 1,
        combat: 0,
        mining: 0,
        // ... other skills
    },

    // ========== REGION TIER & DIFFICULTY ==========
    tier: 1,                             // Region tier (1-10, affects rewards/difficulty)
    difficultyRating: "Easy",            // Display string: Easy, Medium, Hard, Extreme
    recommendedLevel: {
        character: 1,
        combat: 1,
        navigation: 1
    },

    // ========== SPECIAL FEATURES ==========
    features: {
        safeZone: true,                  // Cannot be attacked while navigating here
        fastTravel: false,               // Can fast-travel to this region
        settlement: null,                // Settlement ID if this region contains one
        dungeon: null,                   // Dungeon ID if region has a dungeon

        // Resource bonuses (multipliers)
        resourceBonuses: {
            wood: 1.0,
            ore: 1.0,
            fish: 1.0
        }
    }
}
```

## Biome Schema (Content Template)

Biomes define the pool of content that regions can draw from.

```javascript
{
    name: "Plains",
    description: "Open grasslands with basic resources",
    icon: "🌾",
    color: "#7fb069",                    // Display color for UI

    // Gathering nodes by skill type
    gatheringNodes: {
        mining: ["copperVein", "tinRock"],
        logging: ["oakTree", "birchTree"],
        fishing: ["pond", "stream"],
        hunting: ["grassland"],
        foraging: ["flowerPatch", "berryBush"],
        thieving: ["abandonedCart", "marketStall"]
    },

    // Crafting stations by skill type
    craftingNodes: {
        forging: ["basicForge"],
        machining: ["basicWorkbench"],
        cooking: ["campfire"],
        chemistry: ["chemTable"],
        textiles: ["sewingKit"],
        engineering: ["engineeringDesk"]
    },

    // Discovery rates
    exitPathChance: 0.15,                // Chance to discover path to adjacent region
    nodeDiscoveryWeight: 0.50,           // 50% of discoveries are gathering nodes
    stationDiscoveryWeight: 0.20,        // 20% of discoveries are crafting stations
    enemyDiscoveryWeight: 0.20,          // 20% of discoveries are enemies
    locationDiscoveryWeight: 0.10        // 10% of discoveries are special locations
}
```

## Enemy Assignment to Regions

Enemies are currently assigned to regions based on distance from start:

```javascript
// Current system (in generateWorldMap):
const maxEnemyLevel = Math.max(1, Math.floor(distanceFromStart * 1.5));

// Includes all enemies with level <= maxEnemyLevel
```

**Recommended Enhancement:**
```javascript
// Add region filters to enemy definitions
enemies: {
    scout: {
        level: 1,
        biomes: ["plains", "forest", "coast"],  // Only spawns in these biomes
        minTier: 1,                              // Only in tier 1+ regions
        maxTier: 3,                              // Only in tier 1-3 regions
        spawnWeight: 1.0                         // Relative spawn chance
    }
}
```

## Mission Assignment to Regions

Missions link to regions via the `metadata.region` field:

```javascript
missions: {
    "tutorial_elder": {
        metadata: {
            region: "region_-3_-4",      // Region where mission is available
            category: "tutorial",
            difficulty: 1
        }
    }
}
```

## Discovery System

When players navigate and make discovery attempts:

1. **Discovery Roll**: Check against `discoveryChance` (Perception vs Complication)
2. **Discovery Type**: Weighted random selection based on biome weights
3. **Discovery Target**: Random selection from appropriate pool (nodes/stations/enemies/locations)
4. **Experience Award**: Based on `experienceRates` for the discovery type
5. **State Update**: Add to discovered lists, update discovery progress %

## Implementation Notes

### Current Implementation Status

✅ **Implemented:**
- Basic region structure (name, description, biome, coords)
- Navigation requirements
- Complication system
- Discoverable nodes (from biome)
- Discoverable enemies (distance-based)
- Available missions (reference-based)
- Adjacent regions

⏳ **Partially Implemented:**
- Crafting stations (in biome, not in region state)
- Special locations (no system yet)

❌ **Not Implemented:**
- Experience rates per region
- Environmental effects
- Hazards
- Region tiers/difficulty ratings
- Resource bonuses
- Item/skill gates beyond navigation level
- Settlement/dungeon links

### Migration Path

1. **Phase 1**: Add missing fields to `generateWorldMap()` with default values
2. **Phase 2**: Implement experience rate system in navigation discovery
3. **Phase 3**: Add environmental effects and hazards
4. **Phase 4**: Implement special locations discovery
5. **Phase 5**: Add region tiers and difficulty ratings
6. **Phase 6**: Create settlement/dungeon linking system
